# The Art of Becoming — Janiz

A small, static keepsake made by Grey for Janiz.

## Files
- `index.html` — the complete responsive journal
- `assets/plate-artwork.jpg` — the handmade plate artwork
- `assets/janiz-portrait-daylight.png` — supplied daylight portrait
- `assets/janiz-portrait-monochrome.jpg` — supplied monochrome portrait

## Preview locally
Open `index.html` in a modern browser. Keep the `assets` folder beside it; the page uses relative paths.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `the-art-of-becoming`).
2. Upload **the contents of this folder**, not the ZIP file itself. `index.html` must be in the repository root, with the `assets` folder beside it.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.

## Privacy — please read before sharing
This is a static website. The `noindex,nofollow` setting asks search engines not to index it, but **does not make the site private**. Anyone who obtains the GitHub Pages URL may be able to open it, and visitors can save the images. Do not publish it if Janiz has not agreed to having these photographs shared online. For genuinely private access, use a host that supports access control or a password-protected page; a password typed only into front-end JavaScript is not secure.

The supplied WhatsApp screenshots and phone number are intentionally not published. Private chat screenshots, contact details and unrelated profile/business metadata are not part of this keepsake.

## Editing
You can edit the wording directly in `index.html`. Keep image filenames unchanged unless you also update their paths in the HTML.
